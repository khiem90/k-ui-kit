Add DataTable: a Component that takes column definitions in the TanStack Table shape and a data array, and renders a native table with a caption and scoped column headers. With `sortable`, each column header is a button that cycles ascending, descending, and unsorted, and the sorted column carries aria-sort. With `pageSize`, previous and next Buttons page through the rows and a status line announces the page. A table wider than its container scrolls sideways, and the scrolling region is then a Tab stop named by the caption. The entry also exports the `ColumnDef` type.
