Add Rooftop, a third Theme and the first dark one. Set `data-theme="rooftop"` on the html element, or on any ancestor, and every Component under it turns into the tiny bar on a wet roof: a Wet stone page, Awning panels for the Dialog, the Select list, and the DataTable, Ticket text, Bulb yellow for the primary Button, checked controls, the active tab, and the focus ring, a Stool wood secondary Button, an outline Button with a Ticket edge, a danger Button in a lifted Tail light, fields and controls recessed to the page colour behind a 2px Fog teal edge that turns Bulb on focus, Tabs in a recessed Sign box track, flat 4px Buttons on a black drop shadow, 10px panels with no arch and no Rail, a Sign gold Dialog title, a Sign box overlay, Sign box for hover and selection, and a 2px Bulb ring with a warm glow on the Dialog, Tooltip, and the Select list. Every label, Button, tab, and table header is Big Shoulders Display at 800, uppercase, and body text is Barlow. A Dialog opened from inside a Rooftop subtree is Rooftop too. All three Themes ship in `k-ui-kit/styles.css`. Without the attribute, Ridgeline is unchanged.

A Theme now carries one Color scheme of its own, declared in its block (ADR 0007). Ridgeline and Noren declare `color-scheme: light` and Rooftop declares `color-scheme: dark`, which turns native scrollbars and form controls dark inside a Rooftop subtree, even on a light page. `data-theme` is the only switch; `data-color-scheme` stays reserved and unused.

One colour role is new. `--kui-surface-field` is the fill of a TextField, the Select trigger, the Checkbox box, the Switch track, and the RadioGroup control, split out from `--kui-surface-raised`, which the Select list, the Dialog, the Tooltip, and the DataTable body still read. Ridgeline fills it with Cream and Noren with Paper, the values those parts already drew, so neither renders differently, and an override of it now moves only the fields and controls. Rooftop fills it with Wet stone inside its Awning panels. As under Noren, a `:root` override reaches a Theme set on the html element, and `:root, [data-theme] { ... }` reaches a themed subtree as well.

`k-ui-kit/fonts/rooftop.css` is a third optional stylesheet that loads Big Shoulders Display at 800 and Barlow at 400 from woff2 files inside the package, 63 KB across four files, with each family's SIL Open Font License beside them. Import the one for the Theme you use. The files are the latin and latin-ext subsets, and both families draw the latin-ext range in full, so only Vietnamese and other text outside those ranges falls back along the font stack, to Arial Narrow or Helvetica Neue for signage and `system-ui` for the rest. Without the import, the same fallbacks apply.
