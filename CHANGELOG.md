# k-ui-kit

## 0.1.0

### Minor Changes

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`0a8f208`](https://github.com/khiem90/k-ui-kit/commit/0a8f208033e71b90f5bd26b036cd9765dd9f41c2) Thanks [@khiem90](https://github.com/khiem90)! - Add `hideLabel` to Checkbox. The label leaves the screen and stays in the DOM, so the box keeps its accessible name where its meaning is clear from its surroundings, such as a table row.

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`5a8dddf`](https://github.com/khiem90/k-ui-kit/commit/5a8dddf9f9299def7f1052a64429e92c639994d9) Thanks [@khiem90](https://github.com/khiem90)! - Add Checkbox: a labelled checkbox on the Radix primitive with checked, unchecked, and indeterminate states, controlled or uncontrolled, that submits its name and value with the surrounding form.

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`0a8f208`](https://github.com/khiem90/k-ui-kit/commit/0a8f208033e71b90f5bd26b036cd9765dd9f41c2) Thanks [@khiem90](https://github.com/khiem90)! - Add row selection and the loading and empty states to DataTable. With `selectable`, each row has a Checkbox and the header a select-all that covers the current page and shows mixed while only some of its rows are selected. Each row's box is named after the row's first text or number value, and a selected row carries `data-selected`. Selection is keyed by `getRowId`, controlled through `selectedIds` and `onSelectionChange`, or started from `defaultSelectedIds`. With `loading`, the rows give way to a status announced to assistive technology while the header stays. With no rows, one cell spanning the table shows `emptyMessage`.

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`64341cc`](https://github.com/khiem90/k-ui-kit/commit/64341cc26e2198b635e7fcaec860887b5af23ae4) Thanks [@khiem90](https://github.com/khiem90)! - Add DataTable: a Component that takes column definitions in the TanStack Table shape and a data array, and renders a native table with a caption and scoped column headers. With `sortable`, each column header is a button that cycles ascending, descending, and unsorted, and the sorted column carries aria-sort. With `pageSize`, previous and next Buttons page through the rows and a status line announces the page. A table wider than its container scrolls sideways, and the scrolling region is then a Tab stop named by the caption. The entry also exports the `ColumnDef` type.

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`da7e36d`](https://github.com/khiem90/k-ui-kit/commit/da7e36d631a2a2ba33404c592df669d39ec84fb9) Thanks [@khiem90](https://github.com/khiem90)! - Add Dialog: a composite Component on the Radix primitive with Root, Trigger, Content, Title, Description, and Close parts. Opening it moves focus into the panel and holds it there, the page behind stops scrolling and leaves the accessibility tree, and Escape, a click on the overlay, and the close button each close it and return focus to the trigger. Controlled or uncontrolled, with open and close animations that drop out under reduced motion. Adds the `--kui-overlay` Token for the scrim behind the panel.

- [#1](https://github.com/khiem90/k-ui-kit/pull/1) [`814bf75`](https://github.com/khiem90/k-ui-kit/commit/814bf751fdec1e0cfc1a4504045df300454ca8c4) Thanks [@khiem90](https://github.com/khiem90)! - First release: the Token set with light and dark Themes, and Button with five variants, three sizes, icon slots, and asChild.

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`a72ef7f`](https://github.com/khiem90/k-ui-kit/commit/a72ef7fe0078798cc7b1f82ff8551591c9659e9b) Thanks [@khiem90](https://github.com/khiem90)! - Add RadioGroup: a composite Component on the Radix primitive with Root, Item, and Label parts. Arrow keys move selection, the group is one Tab stop that lands on the selected item, disabled items are skipped, and the selected value submits with the surrounding form under the group's name. Controlled or uncontrolled, with a vertical or horizontal layout.

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`311a7e7`](https://github.com/khiem90/k-ui-kit/commit/311a7e7dbca73171049b74d4d6adfbdb3136e306) Thanks [@khiem90](https://github.com/khiem90)! - Add Select: a composite Component on the Radix primitive with Root, Trigger, Content, Item, and Group parts. The trigger shows the picked option or a placeholder, in the three TextField sizes. Enter, Space, and the arrow keys open the list, arrows move through the options and skip disabled ones, typing jumps to a match, Enter picks, and Escape closes and returns focus to the trigger. A long list scrolls, with a button at either end. Controlled or uncontrolled, and inside a form it submits its value under the name it is given.

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`65cac3b`](https://github.com/khiem90/k-ui-kit/commit/65cac3b0b8de485d48330d639dc58e003b1613e0) Thanks [@khiem90](https://github.com/khiem90)! - Every Component renders from a React Server Component with no client boundary in your app, the composite namespaces such as `Dialog.Root` included. The package ships one file per Component, each with its own client directive, so a bundler also drops the Components an app does not import.

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`1902c84`](https://github.com/khiem90/k-ui-kit/commit/1902c848315f586330cfe31b541a2ebae6338e1f) Thanks [@khiem90](https://github.com/khiem90)! - Add Switch: a labelled on/off switch on the Radix primitive that announces as a switch, toggles with Space, controlled or uncontrolled, and submits its name and value with the surrounding form. Adds the `--kui-radius-full` Token for pill shapes.

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`d25043e`](https://github.com/khiem90/k-ui-kit/commit/d25043e0fec7b1f4f6b5470d4889077f6cee333f) Thanks [@khiem90](https://github.com/khiem90)! - Add Tabs: a composite Component on the Radix primitive with Root, List, Trigger, and Content parts. Arrow keys move between tabs and activate the one they land on, Home and End jump to the first and last, disabled tabs are skipped, and only the active panel is in the Tab order. Controlled or uncontrolled, with a horizontal or vertical layout.

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`cc775bd`](https://github.com/khiem90/k-ui-kit/commit/cc775bd51e017f3587efc17196de329a82a5a201) Thanks [@khiem90](https://github.com/khiem90)! - Add TextField: a labelled native input with an optional description and error message, wired through aria-describedby and aria-invalid, in the three Button sizes.

- [#3](https://github.com/khiem90/k-ui-kit/pull/3) [`08729af`](https://github.com/khiem90/k-ui-kit/commit/08729af6f216208aca55fc96b089c1c15761be09) Thanks [@khiem90](https://github.com/khiem90)! - Add Tooltip: a short description of any focusable element, on the Radix primitive. It opens on hover and keyboard focus, closes on Escape and blur, is read as the trigger's description, and flips to the other side when it would not fit. Controlled or uncontrolled, with a configurable side and hover delay.
