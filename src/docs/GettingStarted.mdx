# Getting started

k-ui-kit is a small set of accessible React Components styled with plain CSS.

## Install

```bash
pnpm add k-ui-kit
```

React 18 or later is a peer dependency.

## Import the stylesheet

Import it once, at the root of your app:

```tsx
import "k-ui-kit/styles.css";
```

## Use a Component

```tsx
import { Button } from "k-ui-kit";

<Button variant="primary">Save</Button>;
```

## Themes

The kit follows the operating system colour scheme. Force a Theme with `data-theme` on any ancestor. The attribute wins over the system preference.

```html
<html data-theme="dark"></html>
```

Every design value is a Token you can override. Your override wins over the kit in both Themes, so give the dark value under the same two selectors the kit uses:

```css
:root {
  --kui-primary: #7c3aed;
}

[data-theme="dark"] {
  --kui-primary: #a78bfa;
}

@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    --kui-primary: #a78bfa;
  }
}
```

If your app always sets `data-theme` on the root, the media query block is not needed.
