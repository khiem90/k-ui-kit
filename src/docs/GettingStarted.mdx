# Getting started

k-ui-kit is a small set of accessible React Components styled with plain CSS. They come dressed in Ridgeline, the kit's one Theme: warm apricot and cream surfaces, Ember for actions, pill Buttons, and an arched Dialog. You get one package, one stylesheet, an optional fonts stylesheet, and Tokens you override.

## Install

```bash
pnpm add k-ui-kit
```

React and React DOM 18 or later are peer dependencies. The kit has no other dependencies, so installing it adds one folder to `node_modules` and every line in it is the kit's own code. The package ships ESM with type declarations, so your bundler keeps only the Components you import and your editor completes their props.

## Import the stylesheet

Import it once, at the root of your app. In Next.js that is `app/layout.tsx`. In Vite it is `src/main.tsx`.

```tsx
import "k-ui-kit/styles.css";
```

That one file carries the Tokens and every Component's styles. Class names and Tokens are prefixed `kui`, so nothing collides with your own CSS. It loads no font files.

## Add the fonts

Ridgeline uses three typefaces. Dialog titles are Fraunces. Labels, Buttons, tabs, and table headers are Josefin Sans. Everything else is Nunito Sans. All three ship inside the package. Import their stylesheet next to the main one:

```tsx
import "k-ui-kit/styles.css";
import "k-ui-kit/fonts.css";
```

Your bundler copies the woff2 files into your build, so you host nothing yourself. They come to 228 KB across seven files, but a browser only fetches the faces and character ranges a page draws. Each family's SIL Open Font License sits beside its files in the package. The faces use `font-display: swap`, so text shows in a fallback font until the file arrives.

Skip this import if your app already serves these families under the same names. The kit's Tokens name them, so your own font-face rules apply. If neither stylesheet provides them, the kit falls back to Georgia for Dialog titles and `system-ui` for the rest.

## Use a Component

```tsx
import { Button } from "k-ui-kit";

<Button variant="primary">Save</Button>;
```

Composite Components are namespaces of parts you assemble yourself:

```tsx
import { Button, Dialog } from "k-ui-kit";

<Dialog.Root>
  <Dialog.Trigger>
    <Button>Open</Button>
  </Dialog.Trigger>
  <Dialog.Content>
    <Dialog.Title>Confirm</Dialog.Title>
    <Dialog.Description>Are you sure?</Dialog.Description>
    <Dialog.Close />
  </Dialog.Content>
</Dialog.Root>;
```

Every Component works inside a React Server Component tree, namespaces included. The package draws its own client boundary, so you never add `"use client"` for it. One limit comes from React rather than the kit. A function cannot travel from the server to the browser, so props such as `onValueChange` or a DataTable `cell` renderer have to come from a client component.

## A form

TextField, Select, Checkbox, and Button share sizes and Tokens, so they line up with no extra CSS. Each one is a native form control, or submits like one, so a plain `form` works and so do form libraries. Select has no label of its own, so this one borrows the label Tokens to match TextField's.

```tsx
import type { CSSProperties } from "react";
import { Button, Checkbox, Select, TextField } from "k-ui-kit";

const labelStyle: CSSProperties = {
  font: "600 0.875rem/1.25rem var(--kui-font-label)",
  textTransform: "var(--kui-label-case)" as CSSProperties["textTransform"],
  letterSpacing: "var(--kui-label-tracking)",
};

export function SignUpForm() {
  return (
    <form
      action="/sign-up"
      method="post"
      style={{ display: "grid", gap: "var(--kui-space-4)", maxWidth: "24rem" }}
    >
      <TextField label="Email" name="email" type="email" autoComplete="email" required />
      <div style={{ display: "grid", gap: "var(--kui-space-2)" }}>
        <label htmlFor="plan" style={labelStyle}>
          Plan
        </label>
        <Select.Root name="plan" defaultValue="free">
          <Select.Trigger id="plan" />
          <Select.Content>
            <Select.Item value="free">Free</Select.Item>
            <Select.Item value="team">Team</Select.Item>
          </Select.Content>
        </Select.Root>
      </div>
      <Checkbox name="terms" label="I agree to the terms" required />
      <Button type="submit">Create account</Button>
    </form>
  );
}
```

## The Ridgeline Theme

Ridgeline applies as soon as the stylesheet loads. There is no attribute to set and no provider to wrap your app in.

Ridgeline has a light Color scheme only. The stylesheet declares `color-scheme: light` and holds no dark values, so the kit looks the same whatever the operating system prefers. A dark mode toggle in your app won't change the kit, so don't wire one up for it. The kit reads no `data-theme` attribute today. That name and `data-color-scheme` are reserved for a second Theme and a dark Color scheme, if either arrives.

## Override Tokens

Every design value is a Token on `:root`: colours, shadows, radii, fonts, label styling, spacing, and motion. Set the ones you want in a plain `:root` rule. The kit wraps its own selector in `:where()`, which carries zero specificity, so your rule wins wherever it sits in the cascade.

```css
:root {
  --kui-primary: #2f6f5e;
  --kui-primary-hover: #1f4d41;
  --kui-focus-ring: #2f6f5e;
  --kui-radius-pill: 12px;
}
```

Token names describe a role, not a colour, so `--kui-primary` still means "the main action" when another Theme arrives. An override applies to everything inside the element that sets it, so a rule on a `section` restyles one part of a page.

The kit checks the contrast of every pair it draws with its own values. When you change a colour, check its pairs yourself: text Tokens need 4.5:1 on the surfaces they sit on, and `--kui-border` and `--kui-focus-ring` need 3:1.

Ember is too faint on the Peach sky tint, so a control drawn there uses its own pair of Tokens. A selected or hovered DataTable row draws its Checkbox in `--kui-primary-on-tint` and `--kui-focus-ring-on-tint`, and the highlighted Select option draws its check in `--kui-primary-on-tint`. If you change `--kui-primary` or `--kui-focus-ring`, set these two as well.
